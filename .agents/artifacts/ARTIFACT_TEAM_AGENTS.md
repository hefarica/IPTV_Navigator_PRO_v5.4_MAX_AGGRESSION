## 3. Workspace Orchestrator (meta-rol)

El "Workspace Orchestrator" no es un archivo separado: es el rol del agente principal (Claude Code en sesión activa) que:

1. Recibe la solicitud del usuario.
2. Ejecuta `iptv-cortex-init-mandatory` 5-layer scan.
3. Determina qué specialists invocar (matriz arriba).
4. Distribuye sub-tareas con `Agent` tool (parallel-safe cuando aplica).
5. Consolida findings.
6. Toma decisión final con evidencia.
7. Reporta al usuario en formato `Analizado / Encontrado / Cambiado / Validado / Faltante / Riesgos / Evidencia / Siguiente`.

## 5. Delegation rules (cuándo NO usar subagentes)

- Tareas single-step triviales → ejecutar directamente
- Cuando el user explicitly dijo "no delegues"
- Tareas que ya están claramente en el dominio del agente principal
- Cuando el subagente NO tiene mejor contexto que el agente principal (sería overhead)

## 6. Doctrine binding (todos los subagents respetan)

- `iptv-cortex-init-mandatory` (primer paso)

- `iptv-omega-no-delete` (mv ≠ rm)
- `iptv-vps-touch-nothing` (zero VPS commands)
