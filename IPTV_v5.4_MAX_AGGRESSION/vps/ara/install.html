APE Crystal Agent

Instalación de primera vez (solo una vez por dispositivo)

⬇ Descargar el APK

Pasos (en el navegador del TV):
  1. Pulsa Descargar el APK (arriba).
  2. Si el TV pide permiso de "orígenes desconocidos / instalar apps", acéptalo para este navegador.
  3. Abre el archivo descargado e instala.
  4. Abre APE Crystal. Desde ahí la app hace TODO sola: túnel seguro, permisos en pantalla y carga de la lista.

Nota honesta: el primer APK se instala desde esta página (Android no permite que una lista de un reproductor de terceros instale apps). Ya instalada, la app no se reinstala: se auto-actualiza sola. Al abrirla te guiará en pantalla para activar Opciones de desarrollador + Depuración inalámbrica y aceptar el permiso — el resto lo hace ella.
