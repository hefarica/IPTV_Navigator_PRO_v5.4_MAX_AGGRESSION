# Grano sintético contra banding

## Regla
El grano enmascara smear y banding; cuesta ~8–12% de bitrate.

## Código
```bash
ffmpeg -i in.ts -vf "noise=alls=6:allf=t+u" -c:v libx265 out.mkv
```

## Antipatrón
Grano excesivo: ruido visible y bitrate inútil.
