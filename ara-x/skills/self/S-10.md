# Ventana HLS de 60 s

## Regla
hls_time=3 y hls_list_size=20 absorben jitter sin crecer sin límite.

## Código
```bash
ffmpeg -i in.ts -c copy -f hls -hls_time 3 -hls_list_size 20 out.m3u8
```

## Antipatrón
HLS con lista infinita: disco y latencia crecientes.
