# CPUQuota persistente

## Regla
systemd CPUQuota limita el canary sin cgcreate manual y sobrevive reboot.

## Código
```bash
systemctl edit ape-canary@CH1; # [Service] CPUQuota=40%
```

## Antipatrón
cgcreate manual: se pierde al reiniciar y no es unificado.
