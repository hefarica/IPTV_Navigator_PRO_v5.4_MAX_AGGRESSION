# MemoryMax e IOWeight

## Regla
MemoryMax y IOWeight evitan que el canary se coma el VPS.

## Código
```bash
systemctl set-property ape-canary@CH1 MemoryMax=1G IOWeight=10 Nice=10
```

## Antipatrón
Sin límites: OOM y contención de I/O.
