# Nunca unsharp antes del scale

## Regla
Afinar antes de escalar amplifica ringing y macrobloques.

## Código
```bash
ffmpeg -i in.ts -vf "scale=3840:2160:flags=lanczos,unsharp=7:7:1.2" out.mkv
```

## Antipatrón
Unsharp previo: halos y artefactos.
