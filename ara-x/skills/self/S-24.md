# Nunca CRF en vivo

## Regla
CRF produce bitrate variable y underrun; usar bitrate/maxrate/bufsize.

## Código
```bash
ffmpeg -i in.ts -c:v libx265 -b:v 25M -maxrate 32M -bufsize 64M out.mkv
```

## Antipatrón
CRF en directo: buffer impredecible y cortes.
