# CPU y rebuffer medidos

## Regla
CPU del proceso <60% y rebuffer <0.5% en 10 min son gates duros.

## Código
```bash
systemd-cgtop -1 | grep ape; curl -s /sync | jq '.metrics.rebuffer_ratio'
```

## Antipatrón
Declarar estable sin medir rebuffer/CPU.
