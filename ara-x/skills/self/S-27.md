# Rollback limpio

## Regla
El rollback deja el canal en origen y sin PID/segmentos residuales.

## Código
```bash
systemctl stop ape-canary@CH1; rm -f /var/www/crystal/CH1.m3u8; pgrep -f ape-visual || true
```

## Antipatrón
Rollback que deja el proceso vivo: no es rollback.
